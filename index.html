Photoshop Delivery Format – Setup Instructions

Before using the Delivery Format automation, please complete the following setup:

  1. 1
    Navigate to the action folder:
    /Volumes/FroQ/1_FROQ/3DPackshotCreators/3D_Training/Salman/Delivery_Formats/Actions/Action
  2. 2
    Open Adobe Photoshop 2024.
  3. 3
    Load all the Photoshop Actions available in the folder into your Photoshop Actions panel.
  4. 4
    Once actions are successfully loaded, press ⌘ Command + Shift + F2 to execute the automation.
Note: The Delivery Format shortcut will function correctly only after all required actions have been loaded.

Normal Map Action – Setup Instructions

Before creating a Normal Map, please complete the following setup:

  1. 1
    Navigate to the following location:
    /Volumes/FroQ/1_FROQ/3DPackshotCreators/3D_Training/Salman/Photoshop_Actions/Normal_Map/Versions/Version_1/Normal_Map.atn
  2. 2
    Open Adobe Photoshop 2024.
  3. 3
    Load the Normal_Map.atn action into the Actions panel.
  4. 4
    Once the action has been successfully loaded, press ⌘ Command + Shift + F1 to activate the action and generate the Normal Map.
Note: The keyboard shortcut will function only after the Normal_Map.atn action has been loaded into Adobe Photoshop.
